CONCLUSION · PATH TO INDEPENDENT STUDY

ผ่านเป้าระดับโมเดลและระบบครบ ขั้นต่อไปคือข้อมูลจริงขององค์กร

ผลเทียบกับเป้า

  • ROC-AUC 0.764 ≥ 0.75 ✔
  • KS 0.399 ≥ 0.35 ✔
  • DI เพศ 0.96 · อายุ 0.83 ≥ 0.8 ✔
  • ~40 ms < 300 ms ✔
  • ลด FPD / เวลาพิจารณา: ต้อง pilot

ข้อจำกัด

  • selection bias: ไม่มี label ของคนที่ถูกปฏิเสธ
  • ใช้ตารางเดียว (ยังไม่ใช้ bureau, ประวัติการผ่อน)
  • cost 5:1 เป็นสมมติฐาน
  • SHAP ไม่ใช่ causal

ต่อยอดเป็น IS

  • เพิ่ม feature จาก bureau / installments
  • เทียบวิธีลด bias หลายแบบ
  • reject inference
  • drift monitoring + retraining policy
  • user study: คำอธิบายช่วยหรือเพิ่ม automation bias
สรุป เป้าหมายระดับโมเดลและระบบผ่านทั้งหมด ทั้ง AUC, KS, fairness และ latency ส่วนเป้าระดับองค์กร เช่น ลด First Payment Default วัดไม่ได้ในงานต้นแบบ ต้องทดลองใช้จริง ข้อจำกัดที่สำคัญคือ selection bias การใช้ข้อมูลเพียงตารางเดียว และ cost ratio ที่เป็นสมมติฐาน สำหรับการต่อยอดเป็น Independent Study ผมวางแผนไว้ 5 ทาง ทางที่สนใจที่สุดคือ user study เพื่อตอบว่าคำอธิบาย SHAP ช่วยให้เจ้าหน้าที่ตัดสินใจดีขึ้นจริง หรือกลับทำให้เชื่อ AI มากเกินไป
