3.1 · TRAINING IMPLEMENTATION

Preprocessing อยู่ใน pipeline เดียวกับโมเดล

Raw CSV

DAYS_* → ปี, Y/N → 0/1, sentinel → NaN

8 domain ratios

DSTI, loan/income, payment rate, ext score mean…

ColumnTransformer

median + missing flag · “Unknown” + one-hot

Classifier

LogReg · RF · HistGradientBoosting

Validation methodology

  • Stratified split 70 / 15 / 15
  • เทียบทุก version บน validation
  • threshold จาก expected cost (FN 5 : FP 1)
  • 5-fold CV ดูความเสถียร · test ใช้ครั้งเดียว

Metrics

  • ROC-AUC · PR-AUC (คลาสส่วนน้อย)
  • KS (มาตรฐาน credit scoring)
  • Brier (calibration) · expected cost
  • fairness · latency · model size

Unit tests (extra)

40

features, ratio math, unseen category, SHAP additivity, reweighing, API contract

การ train แบ่งเป็นขั้นตอนนี้ แปลงข้อมูลดิบให้เป็นหน่วยที่คนเข้าใจ สร้าง domain ratio 8 ตัว เช่นสัดส่วนค่างวดต่อรายได้ แล้วเข้า ColumnTransformer และ classifier ทั้งหมดอยู่ใน sklearn pipeline เดียว จึงไม่เกิด training-serving skew ระหว่างตอน train กับตอนให้บริการผ่าน API การ validate ใช้ split 70 15 15 เลือก threshold จากต้นทุน และใช้ 5-fold CV ดูความเสถียร test set ใช้เพียงครั้งเดียวตอนท้าย ส่วนคะแนนพิเศษ ผมเขียน unit test 40 ตัว
