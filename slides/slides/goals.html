2.1 · SYSTEM OBJECTIVES

เป้าหมาย 4 ระดับ พร้อมตัวชี้วัด

ระดับเป้าหมายMeasurement → Operationalization
Organizationลดหนี้เสียของสินเชื่อใหม่ ตัดสินใจเร็วขึ้นLeading: First Payment Default / 30+ DPD ใน 3 เดือน ลด 15%; ตัดสินใจภายใน 1 วัน ≥ 70%
Systemคะแนนพร้อมเหตุผลแบบ real-time และตรวจสอบได้p95 latency < 300 ms, availability ≥ 99.5%, log ทุก prediction พร้อม model version
Userเจ้าหน้าที่เร็วขึ้นและเข้าใจ AI · ผู้กู้ได้รับความเป็นธรรมเวลาต่อคำขอ ≤ 20 นาที, feedback rate ≥ 30%, Disparate Impact ≥ 0.8
Modelแยกผู้กู้ดี/ไม่ดี ให้ PD ที่ calibrated และเป็นธรรมROC-AUC ≥ 0.75, KS ≥ 0.35, Brier ≤ baseline, gender FPR gap ≤ 0.05

Data collection: prediction log + ระบบติดตามหนี้ (label ล่าช้า 3–12 เดือน) + feedback จาก UI · retrain เมื่อ AUC ลด > 0.03 หรือ PSI > 0.25

Section 2 คือ System Design เริ่มจากเป้าหมาย 4 ระดับตามโจทย์ ระดับองค์กรคือลดหนี้เสีย โดยใช้ leading indicator เป็น First Payment Default ซึ่งเห็นผลภายใน 3 เดือน ไม่ต้องรอ NPL 12 เดือน ระดับระบบคือ latency และการ log ระดับผู้ใช้แบ่งเป็นเจ้าหน้าที่และผู้กู้ ส่วนระดับโมเดลคือ AUC, KS, calibration และ fairness ทุกเป้าหมายมี measurement, แหล่งเก็บข้อมูล และวิธี operationalize ซึ่งรายละเอียดอยู่ในตาราง 2.1.2 ของรายงาน
