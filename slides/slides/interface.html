Section 4 คือ UI-Model Interface ฝั่งซ้ายคือ request ที่ UI ส่งมา มี application id, ตัวเลือกการอธิบาย และข้อมูลผู้กู้ 21 ฟิลด์ ทุกฟิลด์มีการกำหนด enum และช่วงค่าที่ยอมรับ gender ส่งมาได้แต่ใช้เพื่อ audit fairness เท่านั้น ไม่ได้เข้าโมเดล ฝั่งขวาคือ response มี request id สำหรับติดตาม ชื่อและเวอร์ชันโมเดล ผลทำนาย และเหตุผล ทั้งหมดนิยามด้วย Pydantic ซึ่งเป็นแหล่งความจริงเดียว และสร้างเป็นเอกสาร OpenAPI อัตโนมัติ
