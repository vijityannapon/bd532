2.2.3 · ML CANVAS

ML Canvas: Default risk prediction + explanation

Problem & objective

ให้คะแนนความเสี่ยงพร้อมเหตุผลทันที เพื่อลดหนี้เสียและเวลาพิจารณา

Input data

21 ฟิลด์จาก Home Credit; missing สูงใน EXT_SOURCE_1 (56%), sentinel 365243

Processing & model

Pipeline: impute + one-hot + 8 domain ratios → เทียบ 6 versions (LogReg, RF, HistGB)

Expected output

JSON: PD, risk score 0–1000, band, reasons[], warnings[]

Success criteria

ROC-AUC ≥ 0.75, KS ≥ 0.35, Brier ≤ baseline, DI ≥ 0.8, p95 < 300 ms

Decisions & monitoring

threshold จาก cost 5:1 → 3 band; ติดตาม PSI, agreement rate, AUC บน label ใหม่

ML Canvas สรุปงาน AI หลักไว้ในหน้าเดียว ปัญหาคือการให้คะแนนความเสี่ยงพร้อมเหตุผล input เป็นข้อมูลคำขอ 21 ฟิลด์ ซึ่งมีปัญหาค่าขาดหายและค่าแปลก ๆ เช่น 365243 วันที่ใช้แทนคนไม่มีงาน การประมวลผลใช้ sklearn pipeline และเปรียบเทียบโมเดล 6 แบบ output เป็น JSON ที่มีทั้งความน่าจะเป็น คะแนน และเหตุผล เกณฑ์ความสำเร็จมีทั้งด้านความแม่นยำ calibration fairness และความเร็ว การตัดสินใจใช้ threshold ที่คำนวณจากต้นทุน โดยถือว่าการอนุมัติคนที่จะผิดนัดแพงกว่าการปฏิเสธลูกค้าดี 5 เท่า
