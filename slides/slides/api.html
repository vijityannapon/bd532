3.6 · MODEL DEPLOYMENT AS A SERVICE

FastAPI REST service: 5 endpoints พร้อม OpenAPI

MethodPathหน้าที่
GET/healthสถานะ + โมเดลพร้อมหรือไม่
GET/v1/modelversion, features, thresholds, metrics
POST/v1/predictPD, score, band, เหตุผล SHAP, warnings
POST/v1/predict/batchสูงสุด 100 คำขอต่อครั้ง
POST/v1/feedbackfeedback ของเจ้าหน้าที่ + ผลการชำระจริง

Validation: pytest TestClient 22 tests + live runner 17 scenarios + Postman · Swagger ที่ /docs

Scalability

  • Stateless: โหลดโมเดลครั้งเดียว เพิ่ม worker/replica ได้
  • CPU-only ~40 ms ต่อ request รวม SHAP
  • Batch endpoint จำกัดขนาด (413) กัน overload
  • Production: API gateway, queue/DB แทน JSONL, MLflow Registry + canary
หัวข้อ 3.6 โมเดลถูก deploy เป็น REST API ด้วย FastAPI มี 5 endpoint ที่สำคัญคือ predict ซึ่งคืนความน่าจะเป็น คะแนน band และเหตุผล FastAPI สร้างเอกสาร OpenAPI ให้อัตโนมัติที่ /docs การยืนยันว่า deploy แล้วทำงานถูก มีทั้ง unit test ผ่าน TestClient, script ที่ยิงไปยัง server จริง และ Postman ด้านการ scale ระบบเป็น stateless จึงเพิ่มจำนวน worker หรือ replica ได้ตรง ๆ ส่วน production ควรมี API gateway สำหรับ authentication และใช้ MLflow Model Registry สำหรับ rollback
