Fault Tree Analysis มี top event คือการตัดสินใจสินเชื่อผิดพลาดเพราะ AI แยกได้ 2 ทาง G1 คืออนุมัติคนที่จะผิดนัด และ G2 คือปฏิเสธลูกค้าดีหรือไม่เป็นธรรม ทั้งสองทางเป็น AND gate คือโมเดลต้องผิด และมนุษย์ต้องไม่จับได้ด้วย เมื่อหา Minimum Cut Set ได้ 18 ชุด ทุกชุดมีขนาด 2 แปลว่าไม่มี single-point failure ซึ่งเป็นผลจากการออกแบบให้มี human-in-the-loop ข้อสังเกตสำคัญคือ B6 automation bias หรือการเชื่อ AI มากเกินไป อยู่ในหลาย cut set จึงเป็นจุดที่ต้องป้องกันก่อน
