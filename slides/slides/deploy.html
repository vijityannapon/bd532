2.3.2–2.3.3 · DEPLOYMENT & PERFORMANCE

Server-side ใน private cloud ของธนาคาร

✔ Cloud / Server

ข้อมูลส่วนบุคคลอ่อนไหว (PDPA), โมเดลเวอร์ชันเดียวทุกสาขา, log และ audit รวมศูนย์

✘ Edge (เครื่องสาขา)

sync หลายเครื่อง เสี่ยงใช้คนละเวอร์ชัน (B5)

✘ Embedded / mobile

โมเดลถูก reverse-engineer เพื่อ “เล่นระบบ” ได้

2.3.3 · PERFORMANCE FACTORS

~40 ms

Prediction speed: ต่อ request รวมคำอธิบาย (เป้า p95 < 300 ms)

1.5 MB

Model size: เล็ก ใช้ CPU อย่างเดียว ไม่ต้อง GPU

หัวข้อ 2.3.2 และ 2.3.3 ผมเลือก deploy แบบ server-side บน private cloud ของธนาคาร เพราะข้อมูลสินเชื่อเป็นข้อมูลส่วนบุคคลตาม PDPA ทุกสาขาจะใช้โมเดลเวอร์ชันเดียวกัน และ audit ได้ ส่วน edge มีปัญหาเรื่องเวอร์ชันไม่ตรงกัน และ embedded เสี่ยงถูก reverse-engineer สำหรับปัจจัยด้าน performance นอกจาก accuracy ระบบตอบได้ราว 40 มิลลิวินาทีรวมคำอธิบาย และโมเดลมีขนาดแค่ 1.5 MB ใช้ CPU ได้
