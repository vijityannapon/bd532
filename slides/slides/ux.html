2.3.1 · USER EXPERIENCE DESIGN

Prompt + Annotate ไม่ใช่ Automate

Annotate · ทุกเคส

PD, risk score, ค่าเฉลี่ยพอร์ต และเหตุผล ▲/▼ อยู่ข้างข้อมูลคำขอ

Prompt · REVIEW / HIGH

band สีเด่นและคำแนะนำ เช่น “ส่ง senior review”

ไม่ Automate

กระทบชีวิตผู้กู้ ต้องมีผู้รับผิดชอบ และ AUC ~0.76 ยังผิดได้

Feedback loop

เห็นด้วย/ไม่เห็นด้วย + decision + reason code; ผลชำระจริงเป็น label ใหม่

หัวข้อ 2.3.1 คือ UX design ภาพนี้คือหน้าจอจริงของระบบ ซ้ายคือฟอร์มคำขอ ขวาคือผลประเมิน ระดับความ assertive ที่เลือกคือ Prompt กับ Annotate ไม่ Automate Annotate คือแสดง PD คะแนน และเหตุผลในทุกเคส Prompt คือเมื่อเป็นเคสเสี่ยง ระบบจะเน้นสีและบอกให้ส่ง senior review ที่ไม่ automate เพราะการปฏิเสธสินเชื่อกระทบชีวิตคน ต้องมีคนรับผิดชอบ และโมเดลยังผิดได้ ส่วน feedback เจ้าหน้าที่กดเห็นด้วยหรือไม่ พร้อมเลือกเหตุผล ข้อมูลนี้และผลการชำระจริงจะใช้ปรับโมเดลต่อไป
